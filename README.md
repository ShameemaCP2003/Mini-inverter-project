# Mini Inverter Project 

## Overview
This project is a compact mini inverter designed to convert DC power into AC output for low-power applications.

## Features
- Compact inverter circuit
- PCB-based design
- Power conversion system
- Electronic hardware integration

## Tools Used
- KiCad
- PCB Design
- Embedded Electronics

## Project Status
Ongoing Development

## Future Improvements
- Better efficiency
- Battery protection
- Compact enclosure
- Stable output waveform
